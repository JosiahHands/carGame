# Car Game

A 3D driving game. Build your car in the garage, then drive it around a small city
with a car park and a stunt park full of ramps and cones. Drift with the handbrake
for points, and switch between day and night.

In the garage you can change the body style, paint colour and finish, stripes,
window tint, rims, wheel size, tyre width, ride height, spoiler, exhaust,
headlight colour, underglow and number plate. You can also tune power, top speed,
grip, brakes, steering and drift. Your car is saved between sessions.

Runs on macOS, Linux and Windows. It needs [Git](https://git-scm.com) and
[Node.js](https://nodejs.org) 22.12 or newer. On Windows, run the commands in Git Bash.
The game installs into `~/carGame`. Play it with `cd ~/carGame && npm start`,
and press H in the game to see the controls.

Install:

```bash
curl -fsSL https://raw.githubusercontent.com/JosiahHands/carGame/main/install.sh | bash
```

Update:

```bash
curl -fsSL https://raw.githubusercontent.com/JosiahHands/carGame/main/update.sh | bash
```
